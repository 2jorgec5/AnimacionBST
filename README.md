## Descripción del Proyecto
Este repositorio contiene una animación interactiva desarrollada con la biblioteca Manim (Community Edition) para el curso de Algoritmos y Estructuras de Datos. El video final, renderizado en formato MPEG, demuestra el funcionamiento paso a paso de **[INSERTAR ESTRUCTURA/ALGORITMO]**.

## Software Requerido
* Python 3.14
* Biblioteca `manim` (v0.21.0)
* Microsoft C++ Build Tools (para compilación de dependencias gráficas)
* FFmpeg (para codificación de video en formato MPEG)

## Cómo compilar y ejecutar
Para generar la animación, abre la terminal en la raíz del proyecto y ejecuta el siguiente comando:
`manim -pql main.py EscenaEstructura`
*(Nota: `-pql` genera una previsualización rápida en baja calidad. Para compilar el video final en alta resolución según los requisitos, se debe utilizar la bandera `-pqh`).*
